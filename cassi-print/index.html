Como funciona

  1. Você manda a ideia

    Uma foto, um desenho, um link ou só a descrição pelo WhatsApp.

  2. A gente modela

    Criamos o modelo 3D e combinamos tamanho, cores e detalhes.

  3. Camada por camada

    A peça é impressa com cuidado, uma camada de cada vez.

  4. Chega até você

    Acabamento, embalagem e envio para qualquer lugar do Brasil.
